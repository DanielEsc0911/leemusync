# Security policy

Report vulnerabilities privately with GitHub's **Report a vulnerability** button (repository → Security → Advisories). Don't open public issues, discussions or PRs about security problems.

Please include the affected version or commit, the platform, the impact, and steps to reproduce. We'll acknowledge your report and keep you updated until it's fixed and disclosed.

**Supported versions:** none released yet (pre-alpha).

Design and threat model: [docs/specs/security.md](docs/specs/security.md).
