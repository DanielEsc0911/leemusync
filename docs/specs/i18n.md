# Internationalisation

> **Status:** Decided · **Related:** [rules](../rules.md) (P6), [decisions](../decisions.md) (D17, D19, D20), [design-system](ui/design-system.md), [status-and-notifications](ui/status-and-notifications.md), [testing](testing.md) · **Code:** `app/lib/l10n/`, `locales/` (planned)

## Purpose
Every user-facing string exists in English (`en`, source) and neutral Latin American Spanish (`es`) from the first commit that introduces it.

## Sources per layer
| Layer | Format | Location |
|---|---|---|
| Flutter app | ARB + ICU MessageFormat (`gen-l10n`) | `app/lib/l10n/app_en.arb`, `app_es.arb` |
| Rust (tray, desktop notifications, CLI human output) | Fluent `.ftl` | `locales/en/leemusync.ftl`, `locales/es/leemusync.ftl` |
| Android native (notifications, Live Updates, QS tile) | `strings.xml` | `app/android/app/src/main/res/values/`, `values-es/` |
| iOS native (Live Activity, App Intents, permission prompts) | String Catalog `.xcstrings` | `app/ios/` targets |
| Store listings | Text files per locale | `packaging/store/{en,es}/` |

## Rust strings
Fluent keys use the same meaning-based names as ARB (e.g., `status-uploading`). `--json` output is never translated.

## Rules
- No hard-coded user-facing strings. Lints and review enforce this. Log messages are English and are not user-facing.
- Plurals and gender through ICU/Fluent selectors, never string concatenation.
- Keys describe meaning (`statusUploading`), not placement (`homeLabel3`).
- Every ARB entry has an `@key.description` for translators.
- Locale resolution: the OS locale → `es*` uses `es`, everything else uses `en`. Users can override it in Settings.
- Dates, numbers and sizes go through locale-aware formatters (`intl` in Dart).
- Spanish runs about 20–30% longer. Layouts must not clip it. Golden tests render both locales ([testing](testing.md)).

## Parity check
`cargo xtask i18n-check` fails if any locale is missing a key from the English source, or has an extra one. It checks ARB in Phase 0. Each phase that adds a source (Fluent, `strings.xml`, `.xcstrings`) extends the check in the same plan.
