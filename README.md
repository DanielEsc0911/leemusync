# LeemuSync

Keep your emulator saves in sync on every device you play on, using storage you own.

> **Status:** pre-alpha, Phase 0 (foundations). There's nothing to install yet. Roadmap: [docs/progress/roadmap.md](docs/progress/roadmap.md).

LeemuSync (lemur + emu + sync) is an open-source save-sync app for emulators with end-to-end encryption.

- **Any emulator, any folder layout.** Cemu, Dolphin, RetroArch, DuckStation, PCSX2, RPCS3, Azahar, Switch emulators and more, through community emulator profiles. Custom paths are supported.
- **Any storage you own.** S3-compatible (AWS, MinIO, Backblaze B2, Cloudflare R2), WebDAV (Nextcloud, ownCloud), SFTP, local or NAS folders, and later Google Drive, OneDrive, Dropbox and MEGA. There's no LeemuSync server and no account with us.
- **Several players, several machines.** Two people can play the same game on different machines at the same time, and one player can switch machines mid-game. Locks, version history and conflict review mean a save is never silently lost.
- **Every platform, done properly.** Windows, macOS, Linux, Raspberry Pi, Android and iOS. Tray and menu bar icons, Android Live Updates (Now Bar, Super Island), iOS Live Activities and Dynamic Island.
- **English and Spanish** from day one.
